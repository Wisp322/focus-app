# Фокус — приложение-контролёр

Android-приложение, которое в часы, когда ты дома, спрашивает «Чем ты сейчас занят?», а в 23:30 звонит будильником «Пора спать».

## Что умеет
- 5 кнопок: Телефон (спросит через 10 мин), Игры (30 мин), Домашние дела (30 мин), С девушкой (до 22:00), Проекты/учёба (молчит до отбоя).
- Не ответил — спросит снова через 10 минут.
- Три быстрые кнопки прямо в уведомлении.
- Отбой в 23:30 (время меняется), «Ещё 5 минут» при необходимости.
- Режим для каждого дня недели и особые даты (уже добавлены: 28.10.2026 — пропустить, 01.11.2026 — рабочее воскресенье).

## Как получить APK через GitHub
1. Зайди на github.com → **New repository** → имя `focus-app` → **Create repository**.
2. На странице репозитория нажми **uploading an existing file**.
3. Перетащи **всё содержимое** этой папки (включая папку `.github`) и нажми **Commit changes**.
4. Открой вкладку **Actions** — там пойдёт сборка «Собрать APK» (3–5 минут).
5. Когда загорится зелёная галочка, открой справа **Releases** → скачай `focus-app.apk` на телефон.

Если папка `.github` не загрузилась (её не видно в репозитории): **Add file → Create new file**, имя `.github/workflows/build.yml`, вставь содержимое файла `build.yml` из этой папки и сохрани.

## Установка на телефон
1. Открой скачанный `focus-app.apk`, разреши установку из этого источника.
2. Запусти «Фокус» и нажми все жёлтые кнопки в блоке «Нужны разрешения».
3. Нажми «Показать уведомление-вопрос», чтобы проверить.
